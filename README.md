## СУБД

Проект в качестве СУБД используется SQLite. Утилиту для работы с SQLite можно
скачать с сайта  https://sqlite.org/download.html

Изучить что содержится в БД через утилиту можно следующими командами (ниже команды описаны при работе через cmd терминал Windows):
1. Запуск sqlite: `sqlite3.exe`. Рекомендуется добавить путь до файла в переменную среды `PATH`
2. Открыть БД: `.open tracker.db`
3. Получить список таблиц БД: `.tables`
4. Получить схему (описание) таблицы: `.schema <таблица>`
5. Установить режим удобного просмотра таблицы: `.mode table`
6. Выход из sqlite: `.quit`
